# Pre- and post-processing for CMG coupled flow-geomechanical simulations

## Overview
This repo processes and converts a Petrel geomodel into CMG compatible formats, and sets up CMG dat files that fully define fluid flow and geomechanical coupled simulations. With inputs of realizations of reservoir properties (e.g., porosity and permeability) from files generated by a Petrel Uncertainty & Optimization workflow, this repo automatically sets up CMG dat files that will be run by CMG simulators. This repo also extracts results from CMG coupled flow-geomechanical simulations and performs fault slip analysis.
